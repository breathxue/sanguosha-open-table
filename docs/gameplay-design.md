# 三国杀 · 自由牌桌 — 游戏玩法设计

> 版本：基于仓库 `bb8bc7b`（2026‑11‑05）的代码整理，2026‑11‑06。
> 本文描述牌桌**实际实现**的玩法与交互，并给出在这张桌上进行标准局的推荐流程。本桌**不设身份牌**，没有主公、忠臣、反贼、内奸之分，胜负由同桌口头约定。标注「建议」的内容尚未实现。

---

## 1. 设计原则

| 原则 | 含义 | 在代码中的体现 |
| --- | --- | --- |
| 服务器只同步，不裁判 | 没有规则引擎，不判断合法性，不结算伤害，不判胜负 | `performAction` 只校验「牌是否存在、是否可见、目标区域是否存在」 |
| 任意牌到任意区域 | 只要你能看见这张牌，就能把它搬到任何区域 | `move` 动作对目标区域没有类型限制，装备区可以放【杀】 |
| 手牌保密，其余公开 | 手牌只有本人能看；装备、判定、武将、弃牌全桌可见 | `viewFor` 对非本人 `hand` 返回 `null`，只给 `handCount` |
| 牌堆内部不可知 | 任何人都看不到牌堆里的牌和顺序，只能取顶 | 客户端只收到 `deckCounts`，不收到牌堆里的 id |
| 口头裁定 | 出牌、响应、判定、伤害全靠语音或聊天沟通 | 内置聊天与操作记录，记录会脱敏（见 §6.3） |
| 熟人局 | 默认信任同桌的人，没有防作弊和权限分级 | 任何人可改任何人体力、任何人可开局、任何人可洗牌 |

这些原则决定了本桌更像「一张带网络同步的实体桌子」，而不是游戏软件。

## 2. 玩家旅程

```
首页 ──建房/加入──▶ 大厅（lobby） ──任意人点开始──▶ 牌局（playing） ──离开──▶ 首页
  ▲                                                                      │
  └──────────── 刷新 / 断线重连：凭 localStorage 里的会话回到原座位 ◀────┘
```

### 2.1 首页：入席

- 填「你的称呼」，1–12 个字符，空白自动变成「无名侠客」，多余空格会合并。
- 两种入席方式：
  - **开一桌新的**：可选填 5 位房间号（字母数字，大小写不敏感，`0 O 1 I` 不会出现在自动生成的号里）；留空随机。
  - **加入朋友的牌桌**：输入 5 位房间号。房间不存在时，会**直接用这个号建一桌**，输入者成为房主。这意味着朋友之间约定一个暗号就能开桌，不需要先建后发。
- 失败情形：房间号已被占用（建房时）、同名玩家已在房间、房间满 8 人。错误以 toast 提示。
- 成功后会话（房间号、玩家 id、token、称呼）存入 localStorage，URL 变为 `?room=房间号`。

### 2.2 大厅：等人

- 显示房间号、邀请链接（一键复制）、座位列表（在座 n / 8，空位可随时加入）。
- 座位号按加入顺序分配，补最小空位；离开后座位回收。
- 房主有标记，但大厅里房主没有特权。
- **任意玩家**都可以点「开始」，不要求满员，1 人也能开。
- 开局后仍可加入，新来者直接入座、区域为空。

### 2.3 牌局：打牌

见第 4、5 章。

### 2.4 离开与结束

- 点「离开」需要二次确认。离开时自己区域内的所有牌（手牌、装备、判定、武将）进入**弃牌区顶部**，记录写明。
- 房主离开，座位号最小者接任房主。
- 最后一人离开，房间立即销毁。
- 所有人断线超过 2 小时无人回来，房间自动销毁。
- 没有「结束牌局」按钮：一局打完，大家直接离开，或继续用同一桌洗牌再来。

## 3. 牌桌组成

### 3.1 区域与可见性

| 区域 | 归属 | 谁能看 | 谁能动 | 说明 |

### 3.3 桌面布局

- 桌面端：自己的区域在底部展开手牌；其他玩家按座位顺序排列在上方；牌堆与弃牌区在中央；右侧面板是操作记录和聊天。
- 手机端：竖屏单列滚动，记录和聊天收进抽屉；手牌横向滚动。
- 最小适配宽度 430 px；支持系统「减弱动效」。

## 4. 操作手册

所有操作最终落到五种服务器动作：`move`（搬牌）、`moveTop`（取牌堆顶）、`shuffle`（洗牌）、`adjustHp`（调体力）、`setTeam`（队伍标记）。下表列出每个玩家操作的触发方式、服务器行为和记录措辞。

### 4.1 摸牌与翻牌

| 操作 | 桌面 | 手机 | 服务器 | 记录 |
| --- | --- | --- | --- | --- |
| 从牌堆摸一张到自己手牌 | 轻点牌堆 | 轻点牌堆 | `moveTop → 自己手牌` | 「X 从普通牌堆摸了 1 张牌」（不记牌名） |
| 把牌堆顶的牌放到任意区域 | 把牌堆拖到目标区 | 长按牌堆后拖 | `moveTop → 目标` | 到他人手牌：「放入 Y 的手牌区」；到公开区：「翻开【牌名】到 …」 |
| 牌堆顶 → 另一牌堆或牌堆底 | 拖到对方牌堆 / 本牌堆的「牌底」 | 同左 | `moveTop → deck` | 「将牌堆顶的 1 张牌移到 …」 |
| 洗牌 | 牌堆上的洗牌按钮 | 同左 | `shuffle` | 「X 洗乱了普通牌堆」 |

牌堆为空时轻点无效，提示「已经空了」。拖牌堆到它自己的牌顶会提示「这已经是牌堆顶了」。

### 4.2 选牌与搬牌

| 操作 | 桌面 | 手机 | 服务器 |
| --- | --- | --- | --- |
| 选中 / 取消一张牌 | 单击 | 轻点 | 无（本地状态） |
| 多选 | 连续单击多张 | 连续轻点 | 无 |
| 拖一张牌到区域 | 按住拖动，放到高亮区 | 长按 280 ms 抬起，拖到区域松手 | `move` |
| 拖多张牌 | 先多选，再拖其中任意一张 | 同左 | `move`，一次最多 100 张 |
| 用对话框搬牌 | 选中后点「移动至…」 | 同左 | `move` |
| 放回牌堆 | 拖到牌堆时出现「牌顶 / 牌底」两个投放区 | 同左 | `move → deck top/bottom` |

限制与提示：

- 只能选自己能看见的牌（自己手牌 + 所有公开牌）。别人的手牌背面不可点。
- 把牌拖回它当前所在区域会提示「已经在目标区域了」，不发请求。
- 移动已不存在的牌（例如别人刚搬走）提示「有牌已经不在牌桌上了，请刷新后重试」。
- 手机上移动超过 10 px 会取消长按判定，变成滚动；轻点仍是选牌。
- 断线时所有操作被拦截，提示「连接尚未恢复」。
- 每个连接 5 秒内最多 40 个动作，超出提示「操作太快了」。

「移动至…」对话框列出全部目标：武将牌堆顶/底、普通牌堆顶/底、弃牌区、每位玩家的四个区域，当前所在区域标「当前」。

### 4.3 体力

- 每位玩家板子上有 `−` `+` 按钮，每次 ±1，服务器允许单次 ±10（预留给未来的批量调整）。
- 范围 0–99，初始 4。选将后**不会自动**按武将体力上限设置，需手动调。
- 任何人都能调任何人的体力，记录写明「X 将 Y 的体力调整为 n」。
- 体力为 0 不触发任何事件，死亡由玩家口头宣布并自行弃牌。

### 4.4 队伍标记（两队对抗）

- 每位玩家的板子和大厅座位上都有一个「队」按钮，点击在 红队 → 蓝队 → 无 之间循环。
- 任何人都能标记任何人，和体力一样不设权限；大厅阶段就可以分好队。
- 标记后板子左侧出现红色或蓝色竖条，名字旁显示「红队 / 蓝队」徽标，记录写明「X 将 Y 标为红队」。
- 纯展示：不影响出牌、搬牌、聊天或任何判断，队伍胜负仍由玩家口头裁定。

### 4.5 武将

- 开局武将牌堆已洗乱。选将方式由玩家决定：常见做法是每人从武将牌堆摸 2–3 张到手牌（私密），选 1 张拖到自己武将区，其余放回牌堆底。
- 武将区可放多张，可用于双将或「备选」展示。
- 点武将牌上的详情按钮查看技能全文；技能文案采用经典版。

### 4.6 弃牌区

- 任何牌拖到中央弃牌区即弃置，最新的在最上面。
- 「展开」可查看全部弃牌并从中选牌搬走（捡回手牌、回收到牌堆）。
- 弃牌区没有自动洗回牌堆：牌堆摸空后，把弃牌区的牌全选搬回牌堆底，再洗牌。

### 4.7 聊天与记录

- 聊天：200 字以内，8 秒内最多 8 条，保留最近 100 条。
- 记录：每个服务器动作一条，保留最近 160 条。开局、入座、离开等用强调色。
- 脱敏规则：涉及手牌或牌堆的移动只记张数，不记牌名；公开区之间的移动记牌名，≤3 张时逐张列出。

## 5. 推荐流程：在这张桌上打标准局（无身份）

以下是**建议的口头约定**，牌桌不会强制任何一步。

### 5.1 开局准备（以 5 人为例）

1. 胜负规则：开局前口头约定，常见的是「混战，最后存活者胜」或「两队对抗，先灭光对方者胜」。本桌没有身份牌，也不建议用聊天模拟身份。
2. 选将：每人从武将牌堆摸 3 张，选 1 张放武将区，其余放牌堆底。可要求全员先选好再同时放到武将区，避免互相参考。
3. 体力：每人按武将基础体力用 `+/−` 调好。主公技在无身份局里无效，忽略即可。
4. 起始手牌：每人轻点普通牌堆 4 次。
5. 座次：按座位号顺时针，座位 1 先手；也可以由房主指定先手。

### 5.2 回合流程

| 阶段 | 玩家操作 | 桌面上怎么做 |
| --- | --- | --- |
| 准备 | 宣布回合开始 | 聊天说「我的回合」 |
| 判定 | 若判定区有牌，从左到右判定 | 把牌堆顶拖到弃牌区即为「翻判定牌」，口头读结果；乐不思蜀生效则跳过出牌 |
| 摸牌 | 摸 2 张 | 轻点牌堆 2 次 |
| 出牌 | 任意次使用牌 | 把牌拖到弃牌区即「打出」；装备拖到自己装备区；延时锦囊拖到目标判定区 |
| 弃牌 | 手牌数降至体力值 | 多选后拖到弃牌区 |
| 结束 | 宣布结束 | 聊天说「过」 |

### 5.3 常见互动的桌面表达

| 牌 | 推荐操作 |
| --- | --- |
| 杀 / 闪 / 桃 | 拖到弃牌区，口头说明目标；被杀者用闪也拖到弃牌区 |
| 决斗 | 双方轮流把【杀】拖到弃牌区 |
| 过河拆桥 | 目标公开区的牌由使用者直接拖到弃牌区；拆手牌由目标自己随机拖一张 |
| 顺手牵羊 | 公开区的牌由使用者拖到自己手牌；拿手牌由目标把一张拖给对方 |
| 无中生有 | 弃置后自己轻点牌堆 2 次 |
| 五谷丰登 | 使用者把牌堆顶拖到弃牌区 N 次翻开，各人依次从弃牌区拿一张 |
| 乐不思蜀 / 兵粮寸断 / 闪电 | 拖到目标判定区；判定后拖到弃牌区（闪电不中则拖到下家判定区） |
| 装备替换 | 旧装备拖到弃牌区，新装备拖到装备区 |
| 死亡 | 口头宣布；自己把所有区域的牌全选拖到弃牌区，或直接离开牌桌（系统自动弃置） |
| 牌堆摸完 | 弃牌区全选搬到普通牌堆底，然后洗牌 |

### 5.4 其他人数

- 2 人：直接对决，可约定每人双将或起始手牌 6 张增加变化。
- 3–5 人：混战最常见；也可以约定「指定一人为众矢之的」的围攻局。
- 6–8 人：建议两队对抗，用「队」按钮把每人标成红队或蓝队，板子上一眼可辨。

## 6. 异常与边界

| 情形 | 行为 |
| --- | --- |
| 刷新页面 | 凭 localStorage 会话自动回到原座位，牌不丢 |
| 断网 | 状态条显示「网络中断，正在尝试回到牌桌」，自动重连；期间操作被拦截 |
| 换设备 | 新设备没有 token，只能作为新玩家加入；旧座位仍占着，需从旧设备离开 |
| 打开别人的邀请链接但本地有另一桌的会话 | 清掉旧会话，走加入流程 |
| 同名 | 加入被拒，换称呼 |
| 房间满 | 加入被拒 |
| 房间不存在 | 自动创建，自己成为房主 |
| 服务器重启 | 所有房间清空，玩家收到「房间已经结束」回首页 |
| 对手刚搬走你正要拖的牌 | 服务器拒绝，提示刷新重试；状态下一次推送会自动纠正 |

## 7. 文案与反馈规范

- 所有提示走右上角 toast，最多同时 3 条，错误 5.2 秒、其他 3.4 秒自动消失。
- 错误文案口语化（「操作太快了，稍等一下」「牌桌已满」），不出现技术词。
- 记录用第三人称、过去式，关键事件强调色：建房、开局、离开。
- 空状态有引导文案：「牌桌还很安静」「说一声『我摸两张』，比翻记录快」。

## 8. 玩法扩展设计（建议，未实现）

按「不破坏无规则原则、实现成本、对体验提升」排序。

| 优先级 | 功能 | 设计要点 | 涉及改动 |
| --- | --- | --- | --- |
| 高 | 选将后一键设体力 | 武将牌进入武将区时提示「按 n 设置体力？」，仍可拒绝 | 前端提示 + 现有 `adjustHp` |
| 高 | 回合指示 | 房主或当前玩家点「下一位」，高亮当前回合玩家；不限制谁能操作 | 新动作 `setTurn`，`Room.turnPlayerId` |
